# Quickstart: UI Branding & GitHub Link Validation

## Validation Steps

### 1. Launch Application
```bash
cargo run -- gui
```

### 2. Verify Window Icon
- Check window title bar and OS panel/taskbar.
- Icon should display custom MusicBox logo.

### 3. Verify Header Logo
- In the top-left area of the window, verify a compact logo appears immediately to the left of "MusicBox Organizer".

### 4. Verify GitHub Link Button
- In the top-right header toolbar, verify button labeled `GitHub ↗` is visible.
- Click `GitHub ↗`.
- Verify system default browser opens `https://github.com/ijash/musicbox-organizer`.
