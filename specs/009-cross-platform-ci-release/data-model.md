# Data Model: Cross-Platform CI & Automated GitHub Releases (Feature 009)

## 1. Entities & Workflow Models

### Entity: `WorkflowTrigger`
Defines conditions under which `.github/workflows/release.yml` executes.

| Field | Type | Description |
|-------|------|-------------|
| `event` | Enum | `push` (filtered to `tags: ['v*']`) or `workflow_dispatch` |
| `ref` | String | Git ref being processed (`refs/tags/v*` or branch ref) |
| `is_release_run` | Boolean | True if `startsWith(github.ref, 'refs/tags/v')`, false otherwise |

### Entity: `MatrixBuildJob`
Defines parameters for platform-specific build jobs.

| Field | Type | Target Runner | Artifact Name | Archive File |
|-------|------|---------------|---------------|--------------|
| `Linux` | Platform | `ubuntu-latest` | `musicbox-linux` | `musicbox-linux-x86_64.tar.gz` |
| `Windows` | Platform | `windows-latest` | `musicbox-windows` | `musicbox-windows-x86_64.zip` |
| `macOS` | Platform | `macos-latest` | `musicbox-macos` | `musicbox-macos-arm64.tar.gz` |

### Entity: `ReleasePublication`
Defines the final release metadata generated on official tag events.

| Field | Type | Description |
|-------|------|-------------|
| `tag_name` | String | Extracted tag string from `github.ref` (e.g. `v0.2.0`) |
| `release_name` | String | Release title matching tag or generated by GitHub release notes |
| `assets` | List<Path> | `musicbox-linux-x86_64.tar.gz`, `musicbox-windows-x86_64.zip`, `musicbox-macos-arm64.tar.gz`, `SHA256SUMS.txt` |
| `generate_release_notes` | Boolean | `true` (automated GitHub changelog generation based on merged PRs/commits) |

### Entity: `ChecksumManifest` (`SHA256SUMS.txt`)
Cryptographic integrity record for all distributed binaries.

| Record Component | Format | Example |
|------------------|--------|---------|
| Hash | 64 hex characters (SHA-256) | `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855` |
| Space Separator | 2 spaces (POSIX format) | `  ` |
| Target File | Exact archive basename | `musicbox-linux-x86_64.tar.gz` |

## 2. State & Execution Transitions

```text
[Trigger: push v* OR workflow_dispatch]
           │
           ▼
[Build Matrix (Parallel)]
 ├── Linux Job   ──► apt deps ──► cargo test ──► run_gui_tests.sh ──► build --release ──► size check (<2.5MB) ──► tar.gz ──► upload artifact
 ├── Windows Job ──► cargo test --lib ───────────────────────────────► build --release ─────────────────────────► .zip   ──► upload artifact
 └── macOS Job   ──► cargo test --lib ───────────────────────────────► build --release ─────────────────────────► tar.gz ──► upload artifact
           │
           ▼
     [All Succeeded?]
      ├── No  ──► Fail workflow (Abort Release)
      └── Yes ──► Check Trigger Type
                   ├── workflow_dispatch ──► Complete (Artifacts stored, NO release)
                   └── push tag (v*)     ──► [Release Job]
                                               ├── Download all artifacts
                                               ├── Compute SHA256SUMS.txt
                                               └── softprops/action-gh-release@v2
```
